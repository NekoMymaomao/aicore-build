网页基础教程

两套教程，各自十节课。HTML 讲页面结构和内容，PHP 讲服务器端逻辑。

HTML 页面结构与内容 代码可以直接改，点「运行」即时看到效果 PHP 服务器端脚本 代码在服务器上执行，预览是真实的运行输出

HTML基础教程

  1. 01文档基本结构DOCTYPE / html / head / body
  2. 02标题与段落h1~h6 / p
  3. 03文本格式化strong / em / mark / br / hr
  4. 04链接a / href / target
  5. 05图片img / src / alt
  6. 06列表ul / ol / dl
  7. 07表格table / tr / th / td
  8. 08表单input / select / textarea
  9. 09语义化标签header / nav / main / footer
  10. 10块级与行内div / span

PHP基础教程

  1. 01第一个 PHP 程序<?php ?> / echo
  2. 02变量与数据类型$变量 / var_dump
  3. 03字符串操作. / strlen / str_replace
  4. 04数组索引 / 关联 / foreach
  5. 05条件判断if / elseif / 三元
  6. 06循环for / while / foreach
  7. 07函数function / 参数 / return
  8. 08处理表单数据$_GET / isset / 转义
  9. 09文件包含与超全局变量include / $_SERVER
  10. 10类与对象class / 属性 / 方法
用浏览器打开本页即可开始。HTML 部分改代码后点「运行」看效果；PHP 部分展示的是服务器真实执行过的输出，对应的源码在 demos/php/examples/，可以拷到自己的 PHP 环境里运行。
