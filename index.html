HTML 基础教程

十节课，从零认识网页的骨架。

每一课都可以亲手试：在深色的代码框里随意修改，点「运行」，下面的预览框就会重新渲染。

  1. 01文档基本结构DOCTYPE / html / head / body
  2. 02标题与段落h1~h6 / p
  3. 03文本格式化strong / em / mark / br / hr
  4. 04链接a / href / target
  5. 05图片img / src / alt
  6. 06列表ul / ol / dl
  7. 07表格table / tr / th / td
  8. 08表单input / select / textarea
  9. 09语义化标签header / nav / main / footer
  10. 10块级与行内div / span
把所有文件放在同一个文件夹里，用浏览器打开 index.html 即可开始。修改任一文件并保存后，刷新页面就能看到变化。
