08 · 表单

表单是网页收集用户输入的地方：输入框、单选框、下拉菜单都属于它。

知识点

  • <form> 包住整张表单；<input> 是最常用的输入控件，靠 type 决定形态（text 文本、password 密码、radio 单选、checkbox 多选）。
  • <label> 是控件的说明文字。用 for 指向控件的 id 后，点文字也能选中控件。
  • 单选按钮要分成一组时，必须给它们相同的 name，同一组里只能选一个。
  • <select> 配 <option> 做下拉菜单；<textarea> 做多行文本。
  • placeholder 是灰字提示，value 是真正的初始值——两者不要混淆。
