05 · 图片

<img> 是空元素，靠属性描述要显示哪张图、图有多宽。

知识点

  • src 是图片地址，可以是同文件夹里的 photo.jpg，也可以是网络地址。
  • alt 是图片的文字说明：图片加载失败时会显示它，读屏软件也靠它朗读。
  • width 和 height 指定显示尺寸（单位像素），只写一个另一个会等比缩放。
  • 下面示例用的是「base64 图片」——把图片数据直接写进 src，不需要额外图片文件，方便离线演示。你自己练习时换成 src="图片文件名.jpg" 即可。
