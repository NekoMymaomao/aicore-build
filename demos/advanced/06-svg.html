06 · 内联 SVG

SVG 是「用标签画出来的矢量图」——本体就是一段 HTML，不是图片文件，放大多少倍都不会糊。

知识点

  • 基本形状：<rect> 矩形、<circle> 圆、<ellipse> 椭圆、<line> 线、<polyline> 折线、<polygon> 多边形、<path> 任意路径。
  • fill 是填充色，stroke 是描边色，stroke-width 是线宽。
  • viewBox="0 0 宽 高" 定义「画布内部的坐标系」。只改 width/height 而保持 viewBox 不变，整个图形就会等比缩放。
  • <defs> 里可以定义渐变、遮罩等可复用的东西，再用 fill="url(#名字)" 引用。
  • 内联的 SVG（直接写在 HTML 里）能被 CSS 选中、能用 JS 改、能做动画；用 <img src="x.svg"> 引入的 SVG 就没有这些能力，浏览器只把它当普通图片。
