03 · 表格进阶

基础课里的表格只是「能画出来」。这一课讲怎么把表格画得又规矩又好读。

知识点

  • <caption> 是表格标题，写在 table 的第一行子元素位置。
  • <thead> / <tbody> / <tfoot> 把表头、数据体、统计行分开，语义更清楚。
  • <th scope="col"> 表示它是「这一列」的表头，scope="row" 表示「这一行」的表头。读屏软件靠它念出「华东，Q1，120」而不是一堆孤立的数字。
  • <colgroup><col> 可以一次给整列设样式，不用每格都写一遍。
  • colspan 横向跨列，rowspan 纵向跨行。
  • 边框用 CSS 的 border-collapse: collapse 合并；表头背景、隔行变色也都交给 CSS，别再用 border 属性。
