02 · 表单校验

不用写一行 JavaScript，浏览器就能帮你检查用户填得对不对。

知识点

  • required：必填，空着就不让提交。
  • type="email"、type="url"、type="number" 自带格式检查，不用自己写正则。
  • minlength / maxlength 限制长度；min / max / step 限制数值范围。
  • pattern 用正则约束输入格式，浏览器会自动在两端补上 ^ 和 $。
  • 校验发生在提交的那一刻：不合法的字段会被拦下并弹出提示。
  • CSS 的 :valid / :invalid 能按校验结果显示不同样式；:placeholder-shown 用来判断「还没输入」，避免一打开就满屏飘红。
  • 加 novalidate 到 <form> 上可以关掉这套原生校验。
