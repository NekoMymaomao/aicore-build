07 · Canvas 绘图

<canvas> 是一块空白画布，你用 JavaScript 在上面下笔画图。图表、游戏画面都靠它。

知识点

  • <canvas width="360" height="200"> 的两个尺寸是画布真实像素，和 CSS 里的显示宽度是两回事。
  • 画图靠 getContext('2d') 拿到的「画笔」对象，后面的操作都通过它进行。
  • fillRect 画实心矩形、strokeRect 画空心矩形、fillStyle/strokeStyle 设颜色、lineWidth 设线宽。
  • 圆形和任意形状要先用 beginPath() 开始一条路径，再用 moveTo/lineTo/arc 描述，最后 fill() 或 stroke()。
  • fillText() 写字，font 设字体（和 CSS 的 font 简写格式一样）。
  • Canvas 画出来的是像素，画完就没了，无法用 CSS 选中里面的图形，也不能放大不失真——这是它和 SVG 最本质的区别。
