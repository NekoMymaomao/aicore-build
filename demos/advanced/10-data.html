10 · 自定义数据与模板

最后一课：给标签挂上自己的数据、把 HTML 片段存起来复用、以及让任何一块内容都能编辑。

知识点

  • data-* 是 HTML 官方留给你的自定义属性：data-id="101"、data-price="39"。
  • JS 里用 element.dataset 读，连字符会变成驼峰：data-price → dataset.price。
  • 用 data-* 存数据的好处：元素被克隆、移动、排序时，数据跟着它一起走，不用另外维护一张表。
  • <template> 里的内容不会显示，也不会加载里面的图片，纯粹是一份「模板」，要用 JS 克隆（content.cloneNode(true)）才会出现在页面上。
  • contenteditable="true" 让任何元素变成可编辑区：打字、光标、输入法（中文候选框）浏览器都帮你处理好了。
  • hidden 属性可以直接隐藏元素，等同于 CSS 的 display: none。
