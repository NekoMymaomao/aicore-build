05 · 条件判断

让程序根据不同情况走不同的分支，靠的就是 if。

知识点

  • 写法：if (条件) { ... } elseif (另一个条件) { ... } else { ... }。
  • 比较运算符：== 相等、!= 不等、> < >= <=。
  • === 是严格比较：值和类型都要相同。0 == "0" 为真，0 === "0" 为假，这是 PHP 里很容易踩的坑。
  • 逻辑运算符：&& 并且、|| 或者、! 取反。
  • 三元运算符 条件 ? 真时的值 : 假时的值，适合做简单的二选一。
