07 · 函数

把一段常用逻辑包成函数，起个名字，以后一行就能调用它。

知识点

  • 定义：function 名字(参数) { ... return 结果; }。
  • 参数可以有默认值，例如 function greet($name, $greeting = "你好")；调用时省略就使用默认值。
  • return 把结果交回给调用处，并立刻结束函数。没写 return 就返回 null。
  • 函数内部定义的变量不会影响外面，这叫作用域；要在函数里改外面的变量得用 global 或参数传递。
  • PHP 自带大量内置函数（max()、array_sum()、sqrt()、round()…），用法和自己写的函数一样。
  • 示例里 "{$greeting}，{$name}！" 用了花括号：变量后面紧跟中文时这样写才不会被误读（详见第 2 课）。
