01 · 第一个 PHP 程序

PHP 是运行在服务器上的脚本语言：它先执行一遍，把生成的 HTML 发给浏览器。

知识点

  • PHP 代码写在 <?php 和 ?> 之间，文件后缀是 .php。
  • echo 用来输出内容——输出什么，浏览器就显示什么。
  • PHP 可以和 HTML 混排：标签外面的部分是普通 HTML，标签里面的部分交给服务器执行。
  • 浏览器拿到的是执行结果，看不到 PHP 源码。这就是 PHP 必须放在服务器上跑的原因。
