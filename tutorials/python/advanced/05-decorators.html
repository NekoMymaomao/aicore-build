装饰器与生成器

装饰器在不改动原函数的前提下增强功能；生成器惰性产出序列。

知识点

  • 装饰器是接收函数、返回新函数的函数，用 @ 语法应用。
  • functools.wraps 保留原函数的元信息。
  • yield 让函数变成生成器，按需产出值，省内存。
decorators.py 
from functools import wraps

def log(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("调用：", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b):
    return a + b

print("结果：", add(3, 4))

def countdown(n):
    while n > 0:
        yield n
        n -= 1

print(list(countdown(5)))
