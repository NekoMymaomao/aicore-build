异常处理

异常让程序在出错时可控地处理问题，而不是直接崩溃。

知识点

  • try / except / else / finally 控制错误处理流程。
  • 捕获具体异常类型更精确；raise 主动抛出异常。
  • 自定义异常通过继承 Exception 实现。
exceptions.py 
def safe_div(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "除数不能为 0"
    finally:
        print("计算完成")

print(safe_div(10, 2))
print(safe_div(10, 0))

try:
    age = int("abc")
except ValueError as e:
    print("转换失败：", e)
