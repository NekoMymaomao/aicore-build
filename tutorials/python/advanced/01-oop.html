面向对象

用类把数据和操作封装在一起，组织更复杂的程序。

知识点

  • class 定义类，__init__ 是构造方法，self 指实例自身。
  • 继承：子类复用并扩展父类；super() 调用父类方法。
  • __str__ 等魔术方法定义对象的字符串表示与运算行为。
oop.py 
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def __str__(self):
        return f"Animal({self.name})"

class Dog(Animal):
    def speak(self):
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

for a in [Dog("旺财"), Cat("咪咪")]:
    print(a.name, "说", a.speak())
print(Dog("旺财"))
