推导式与常用标准库

推导式让构造容器更简洁；标准库提供强大的现成工具。

知识点

  • 列表/字典/集合推导式：[x*x for x in ...]。
  • collections 提供 Counter、defaultdict 等。
  • enumerate 同时取下标和值，zip 并行遍历多条序列。
stdlib.py 
squares = [x * x for x in range(1, 6)]
print("平方表：", squares)

evens = [x for x in range(10) if x % 2 == 0]
print("偶数：", evens)

from collections import Counter
words = "the quick the lazy the".split()
print("词频：", Counter(words))

for i, name in enumerate(["甲", "乙", "丙"], start=1):
    print(i, name)
