文件与上下文管理器

with 语句自动管理资源，确保文件用完后被正确关闭。

知识点

  • with open(...) as f 打开文件，退出代码块自动关闭。
  • 模式："r" 读、"w" 写、"a" 追加。
  • read() / readlines() / write() 读写内容。
files.py 
with open("demo.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")

with open("demo.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())

# 自定义上下文管理器
class Timer:
    def __enter__(self):
        print("开始")
        return self
    def __exit__(self, *args):
        print("结束")

with Timer():
    print("处理中")
