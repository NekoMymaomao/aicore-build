模块与包

把代码拆成模块，通过 import 复用；标准库提供了大量现成工具。

知识点

  • import 引入模块，from ... import ... 引入具体成员。
  • 常用标准库：math、random、datetime、json。
  • if __name__ == "__main__": 区分被导入还是直接运行。
modules.py 
import math
import json
from datetime import date

print("圆周率：", round(math.pi, 4))
print("平方根：", math.sqrt(16))

data = {"name": "小明", "age": 20}
text = json.dumps(data, ensure_ascii=False)
print("JSON：", text)
print("解析回来：", json.loads(text)["name"])

print("今天：", date.today())
