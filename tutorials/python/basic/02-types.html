变量与数据类型

Python 是动态类型语言，变量不需要提前声明类型。

知识点

  • 常见类型：int、float、str、bool、None。
  • type() 查看类型，int()/str() 等做类型转换。
  • f-string（f"...{x}..."）是推荐的字符串格式化方式。
types.py 
age = 18
height = 1.75
name = "小明"
is_student = True

print(type(age))
print(f"{name} 今年 {age} 岁，身高 {height} 米")
print("是否学生：", is_student)
print("数字转字符串：", str(age) + " 岁")
