运算符与输入输出

运算符用于计算和判断；input 从终端读取输入（字符串）。

知识点

  • 算术：+ - * / // % **，其中 // 是整除，** 是幂。
  • 比较产生布尔值；逻辑用 and / or / not。
  • input() 返回字符串，做数值运算前要 int() 转换。
operators.py 
a = 17
b = 5
print("和：", a + b)
print("整除：", a // b)
print("余数：", a % b)
print("幂：", 2 ** 10)
print("比较：", a > b, a == b)

# 浏览器内无法读取标准输入，这里用固定值模拟
age = int("20")
print("明年", age + 1, "岁")
