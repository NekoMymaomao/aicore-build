函数

用 def 定义函数，把逻辑封装成可复用的单元。

知识点

  • def 定义函数，return 返回值。
  • 支持默认参数、关键字参数、可变参数 *args / **kwargs。
  • 函数是一等对象，可以赋值给变量、作为参数传递。
functions.py 
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

def total(*nums):
    return sum(nums)

print(greet("小明"))
print(greet("Bob", greeting="Hello"))
print("求和：", total(1, 2, 3, 4))

square = lambda x: x * x
print("5 的平方：", square(5))
