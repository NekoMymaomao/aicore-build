列表 / 元组 / 字典 / 集合

容器用来一次保存多个值，各有适用场景。

知识点

  • list 有序可变；tuple 有序不可变。
  • dict 键值对；set 无序去重。
  • 通过下标、切片、in、遍历等方式访问元素。
containers.py 
fruits = ["apple", "banana", "cherry"]
fruits.append("date")
print(fruits)
print("第一个：", fruits[0])
print("切片：", fruits[1:3])

point = (3, 4)
print("坐标：", point)

scores = {"math": 95, "english": 88}
print("数学成绩：", scores["math"])
print("所有科目：", list(scores.keys()))

nums = {1, 2, 2, 3, 3, 3}
print("去重后：", nums)
