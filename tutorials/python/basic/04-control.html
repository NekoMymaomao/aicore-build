条件与循环

缩进决定代码块层级，条件与循环控制程序流程。

知识点

  • if / elif / else 分支，条件后要跟冒号。
  • for x in ... 遍历序列，range(n) 生成整数序列。
  • while 条件为真时循环；break / continue 控制循环。
control.py 
score = 86
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

total = 0
for i in range(1, 6):
    total += i
print("1+2+3+4+5 =", total)

n = 3
while n > 0:
    print("倒计时", n)
    n -= 1
