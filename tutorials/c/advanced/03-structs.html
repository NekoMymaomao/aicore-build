结构体与联合体

结构体把不同类型的数据打包成一个整体，描述现实中的对象。

知识点

  • struct 定义自定义类型；. 访问成员，指针用 ->。
  • typedef 给类型起别名，简化书写。
  • union 的成员共用同一块内存，同一时刻只有一个有效。
structs.c 
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[20];
    int age;
} Student;

int main(void) {
    Student s;
    strcpy(s.name, "小明");
    s.age = 20;

    Student *p = &s;
    printf("%s 今年 %d 岁\n", p->name, p->age);
    return 0;
}
运行结果（示意）
小明 今年 20 岁
