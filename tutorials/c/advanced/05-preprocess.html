预处理与头文件

预处理在编译前进行，负责宏替换、文件包含和条件编译。

知识点

  • #define 定义常量或宏，替换发生在编译之前。
  • #include 把别的文件内容包含进来；自定义头文件用双引号。
  • #ifdef / #ifndef 条件编译，头文件保护避免重复包含。
preprocess.c 
#include <stdio.h>

#define PI 3.14159
#define SQUARE(x) ((x) * (x))

int main(void) {
    printf("PI = %.5f\n", PI);
    printf("3 的平方 = %d\n", SQUARE(3));
#ifdef DEBUG
    printf("调试模式\n");
#else
    printf("发布模式\n");
#endif
    return 0;
}
运行结果（示意）
PI = 3.14159
3 的平方 = 9
