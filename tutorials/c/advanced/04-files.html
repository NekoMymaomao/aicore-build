文件操作

程序可以把数据持久化到文件，也能读取文件内容。

知识点

  • FILE * 是文件句柄；fopen 打开，fclose 关闭。
  • 常用模式："r" 只读、"w" 覆盖写、"a" 追加。
  • 写用 fprintf，读用 fgets / fscanf；操作后要检查返回值。
files.c 
#include <stdio.h>

int main(void) {
    // 写入
    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) return 1;
    fprintf(fp, "第一行\n第二行\n");
    fclose(fp);

    // 读取
    char line[100];
    fp = fopen("data.txt", "r");
    if (fp == NULL) return 1;
    while (fgets(line, sizeof(line), fp) != NULL) {
        printf("%s", line);
    }
    fclose(fp);
    return 0;
}
