指针

指针保存的是内存地址，是 C 最核心也最容易出错的概念。

知识点

  • &x 取变量地址，*p 解引用取出该地址的值。
  • 指针作为参数可以让函数修改调用方的变量。
  • 指针与数组关系紧密：数组名可退化为指向首元素的指针。
pointers.c 
#include <stdio.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 1, y = 2;
    printf("交换前：x=%d y=%d\n", x, y);
    swap(&x, &y);
    printf("交换后：x=%d y=%d\n", x, y);

    int arr[3] = {5, 6, 7};
    int *p = arr;
    printf("*(p+1) = %d\n", *(p + 1));
    return 0;
}
运行结果（示意）
交换前：x=1 y=2
交换后：x=2 y=1
*(p+1) = 6
