动态内存分配

运行时按需申请堆内存，用完必须释放，否则内存泄漏。

知识点

  • malloc 申请、calloc 申请并清零、realloc 调整大小、free 释放。
  • 申请后要检查是否返回 NULL（申请失败）。
  • 每一处 malloc 都应有对应的 free。
memory.c 
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arr = malloc(n * sizeof(int));
    if (arr == NULL) {
        fprintf(stderr, "内存申请失败\n");
        return 1;
    }
    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * (i + 1);
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    free(arr);
    return 0;
}
运行结果（示意）
1 4 9 16 25
