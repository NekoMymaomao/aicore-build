函数指针与递归

函数指针让函数也能作为参数传递；递归是函数调用自身求解问题。

知识点

  • 函数指针声明：int (*fp)(int, int)，指向返回 int、接收两个 int 的函数。
  • 把函数指针作为参数即可实现回调。
  • 递归要有终止条件，否则会栈溢出。
funcptr.c 
#include <stdio.h>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

int apply(int (*op)(int, int), int a, int b) {
    return op(a, b);
}

long factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

int main(void) {
    printf("apply(add, 3, 5) = %d\n", apply(add, 3, 5));
    printf("apply(mul, 3, 5) = %d\n", apply(mul, 3, 5));
    printf("5! = %ld\n", factorial(5));
    return 0;
}
运行结果（示意）
apply(add, 3, 5) = 8
apply(mul, 3, 5) = 15
5! = 120
