条件与循环

控制流决定程序走哪条路、重复多少次。

知识点

  • if / else if / else 分支；switch 多分支选择。
  • for 适合已知次数的循环，while / do-while 适合条件循环。
  • break 跳出循环，continue 跳过本次进入下一次。
control.c 
#include <stdio.h>

int main(void) {
    // 根据成绩判断等级
    int score = 86;
    if (score >= 90)      printf("优秀\n");
    else if (score >= 60) printf("及格\n");
    else                  printf("不及格\n");

    // 计算 1 到 5 的和
    int sum = 0;
    for (int i = 1; i <= 5; i++) {
        sum += i;
    }
    printf("1+2+3+4+5 = %d\n", sum);
    return 0;
}
运行结果（示意）
及格
1+2+3+4+5 = 15
