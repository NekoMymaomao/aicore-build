函数

函数把可复用的一段逻辑封装起来，是组织代码的基本单位。

知识点

  • 函数由返回类型、函数名、参数列表和函数体组成。
  • 先声明（原型）后使用；参数按值传递，函数内修改不影响调用方。
  • void 表示不返回或不接收参数。
functions.c 
#include <stdio.h>

// 函数声明（原型）
int add(int x, int y);
int max_of(int a, int b);

int main(void) {
    printf("3 + 4 = %d\n", add(3, 4));
    printf("max(10, 7) = %d\n", max_of(10, 7));
    return 0;
}

int add(int x, int y) {
    return x + y;
}

int max_of(int a, int b) {
    return a > b ? a : b;
}
运行结果（示意）
3 + 4 = 7
max(10, 7) = 10
