运算符与表达式

运算符把变量和常量组合成表达式，是控制流的基础。

知识点

  • 算术运算符 + - * / %；两个整数相除会截断小数部分。
  • 比较运算符 == != > < >= <= 结果为 0（假）或 1（真）。
  • 逻辑运算符 && 与、|| 或、! 非。
  • 自增自减 ++ --；强制类型转换 (double) a / b。
operators.c 
#include <stdio.h>

int main(void) {
    int a = 7, b = 2;
    printf("整数除法 7 / 2 = %d\n", a / b);
    printf("浮点除法 7 / 2 = %.2f\n", (double) a / b);
    printf("取余 7 %% 2 = %d\n", a % b);
    printf("(a > b) = %d\n", a > b);
    printf("(a > 0 && b > 0) = %d\n", a > 0 && b > 0);
    return 0;
}
运行结果（示意）
整数除法 7 / 2 = 3
浮点除法 7 / 2 = 3.50
取余 7 % 2 = 1
(a > b) = 1
(a > 0 && b > 0) = 1
