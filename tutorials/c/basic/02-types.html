变量与数据类型

变量是存放数据的容器，使用前必须先声明类型，类型决定取值范围与内存占用。

知识点

  • int 整数、double 双精度浮点、char 单个字符。
  • 格式化占位符：%d 整数、%.2f 保留两位小数、%c 字符、%s 字符串。
  • sizeof 返回类型或变量占用的字节数（size_t 用 %zu 打印）。
types.c 
#include <stdio.h>

int main(void) {
    int age = 18;
    double height = 1.75;
    char grade = 'A';

    printf("年龄：%d 岁\n", age);
    printf("身高：%.2f 米\n", height);
    printf("等级：%c\n", grade);
    printf("int 占用 %zu 字节\n", sizeof(int));
    return 0;
}
运行结果（示意）
年龄：18 岁
身高：1.75 米
等级：A
int 占用 4 字节
