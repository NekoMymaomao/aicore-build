数组与字符串

数组是相同类型元素的连续集合；C 里字符串就是字符数组。

知识点

  • 数组下标从 0 开始，长度固定，越界访问是未定义行为。
  • 字符串是末尾带 \0 的字符数组。
  • <string.h> 提供 strlen（长度）、strcpy（复制）、strcmp（比较）。
arrays.c 
#include <stdio.h>
#include <string.h>

int main(void) {
    int nums[5] = {10, 20, 30, 40, 50};
    int total = 0;
    for (int i = 0; i < 5; i++) {
        total += nums[i];
    }
    printf("总和 = %d\n", total);

    char name[32] = "C Language";
    printf("长度 = %zu\n", strlen(name));
    return 0;
}
运行结果（示意）
总和 = 150
长度 = 10
