第一个程序：Hello, World

C 是编译型语言：写好源码后先用编译器编译成可执行文件，再运行。

知识点

  • #include <stdio.h> 引入标准输入输出库，printf 就来自这里。
  • int main(void) 是程序入口，操作系统从这里开始执行。
  • 每条语句以分号 ; 结尾。
  • return 0; 表示程序正常结束。
  • 编译：gcc hello.c -o hello；运行：./hello。
hello.c 
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
运行结果（示意）
Hello, World!
