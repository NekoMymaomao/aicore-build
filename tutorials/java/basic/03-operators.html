运算符与控制流

运算符和流程控制构成程序的逻辑骨架。

知识点

  • 算术、比较、逻辑运算符与 C 类似；&& || 短路求值。
  • if / else if / else、switch、for、while。
  • 增强 for 循环 for (int x : arr) 遍历数组或集合。
Control.java 
public class Control {
    public static void main(String[] args) {
        int score = 86;
        if (score >= 90) {
            System.out.println("优秀");
        } else if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }

        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum += i;
        }
        System.out.println("1+2+3+4+5 = " + sum);
    }
}
运行结果（示意）
及格
1+2+3+4+5 = 15
