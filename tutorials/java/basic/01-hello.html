第一个程序与 JDK

Java 代码先编译成字节码，再由 JVM 运行，因此可跨平台。

知识点

  • 类名必须与文件名一致（Hello 对应 Hello.java）。
  • public static void main(String[] args) 是程序入口。
  • System.out.println 输出并换行；编译 javac Hello.java，运行 java Hello。
Hello.java 
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
        System.out.println("欢迎学习 Java");
    }
}
运行结果（示意）
Hello, World!
欢迎学习 Java
