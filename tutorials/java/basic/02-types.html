变量与数据类型

Java 是静态类型语言，变量必须先声明类型。

知识点

  • 八种基本类型：int long double float boolean char byte short。
  • String 是引用类型，用双引号表示。
  • 字符串拼接用 +；final 定义常量。
Types.java 
public class Types {
    public static void main(String[] args) {
        int age = 18;
        double height = 1.75;
        boolean isStudent = true;
        String name = "小明";
        final int MAX = 100;

        System.out.println(name + " 今年 " + age + " 岁");
        System.out.println("身高：" + height);
        System.out.println("是否学生：" + isStudent);
        System.out.println("上限：" + MAX);
    }
}
运行结果（示意）
小明 今年 18 岁
身高：1.75
是否学生：true
上限：100
