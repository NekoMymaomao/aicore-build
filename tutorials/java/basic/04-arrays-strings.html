数组与字符串

数组是定长同类型集合，字符串提供了丰富的处理方法。

知识点

  • 数组长度用 arr.length，下标从 0 开始。
  • String 常用方法：length()、charAt()、substring()、toUpperCase()。
  • StringBuilder 适合频繁拼接。
ArraysStrings.java 
public class ArraysStrings {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50};
        int total = 0;
        for (int n : nums) {
            total += n;
        }
        System.out.println("总和 = " + total);

        String s = "hello java";
        System.out.println("长度 = " + s.length());
        System.out.println("大写 = " + s.toUpperCase());
        System.out.println("子串 = " + s.substring(0, 5));
    }
}
运行结果（示意）
总和 = 150
长度 = 10
大写 = HELLO JAVA
子串 = hello
