集合框架

集合框架提供了动态、功能丰富的容器。

知识点

  • List 有序可重复（ArrayList）。
  • Set 去重（HashSet）。
  • Map 键值对（HashMap）；泛型指定元素类型。
CollectionsDemo.java 
import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("apple");
        fruits.add("banana");
        fruits.add("apple");
        System.out.println("列表：" + fruits);

        Set<String> unique = new HashSet<>(fruits);
        System.out.println("去重：" + unique);

        Map<String, Integer> scores = new HashMap<>();
        scores.put("math", 95);
        scores.put("english", 88);
        System.out.println("数学：" + scores.get("math"));
        System.out.println("科目：" + scores.keySet());
    }
}
运行结果（示意）
列表：[apple, banana, apple]
去重：[banana, apple]
数学：95
科目：[english, math]
