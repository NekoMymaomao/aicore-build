多线程与 Lambda

多线程让任务并发执行；Lambda 让函数式写法更简洁。

知识点

  • 继承 Thread 或实现 Runnable 创建线程。
  • start() 启动线程，join() 等待结束。
  • Lambda：(a, b) -> a + b，配合函数式接口使用。
ThreadsLambda.java 
import java.util.*;

public class ThreadsLambda {
    public static void main(String[] args) throws InterruptedException {
        Thread t = new Thread(() -> {
            for (int i = 1; i <= 3; i++) {
                System.out.println("子线程 " + i);
            }
        });
        t.start();
        t.join();
        System.out.println("主线程结束");

        List<Integer> nums = Arrays.asList(3, 1, 2);
        nums.sort((a, b) -> a - b);
        System.out.println("排序后：" + nums);
    }
}
运行结果（示意）
子线程 1
子线程 2
子线程 3
主线程结束
排序后：[1, 2, 3]
