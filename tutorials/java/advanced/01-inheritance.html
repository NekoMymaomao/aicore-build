继承与多态

继承复用父类能力，多态让同一调用表现出不同行为。

知识点

  • extends 继承父类；@Override 重写方法。
  • 父类引用可以指向子类对象（向上转型）。
  • super 调用父类构造或方法。
Animals.java 
class Animal {
    String name;
    Animal(String name) { this.name = name; }
    String speak() { return "..."; }
}

class Dog extends Animal {
    Dog(String name) { super(name); }
    @Override String speak() { return "汪汪"; }
}

class Cat extends Animal {
    Cat(String name) { super(name); }
    @Override String speak() { return "喵喵"; }
}

public class Animals {
    public static void main(String[] args) {
        Animal[] zoo = { new Dog("旺财"), new Cat("咪咪") };
        for (Animal a : zoo) {
            System.out.println(a.name + " 说 " + a.speak());
        }
    }
}
运行结果（示意）
旺财 说 汪汪
咪咪 说 喵喵
