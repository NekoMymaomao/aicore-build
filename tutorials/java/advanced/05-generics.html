泛型

泛型让类型作为参数，提供编译期类型安全。

知识点

  • class Box<T> 定义类型参数。
  • 泛型方法：<T> T identity(T x)。
  • 通配符 ? 与 ? extends / super 用于灵活匹配。
Generics.java 
class Box<T> {
    private T value;
    Box(T value) { this.value = value; }
    T get() { return value; }
}

public class Generics {
    static <T> void printAll(T[] arr) {
        for (T x : arr) {
            System.out.print(x + " ");
        }
        System.out.println();
    }

    public static void main(String[] args) {
        Box<String> b = new Box<>("你好");
        System.out.println(b.get());

        Integer[] nums = {1, 2, 3};
        printAll(nums);
    }
}
运行结果（示意）
