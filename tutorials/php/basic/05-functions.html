函数

用 function 定义函数，支持默认参数与可变参数。

知识点

  • function 定义函数，return 返回值。
  • 支持默认参数值、类型声明、可变参数 ...$args。
  • 匿名函数（闭包）用 function () use ($x) {}。
functions.php 
<?php
function greet($name, $greeting = "你好") {
    return "$greeting，$name！";
}

function total(...$nums) {
    return array_sum($nums);
}

echo greet("小明") . "\n";
echo greet("Bob", "Hello") . "\n";
echo "求和：" . total(1, 2, 3, 4) . "\n";

$double = fn($x) => $x * 2;
echo "5 翻倍：" . $double(5) . "\n";
?>
运行结果（示意）
你好，小明！
Hello，Bob！
求和：10
5 翻倍：10
