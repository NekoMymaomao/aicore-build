数组

PHP 的数组既能当列表也能当字典，功能强大。

知识点

  • 索引数组：[1, 2, 3]；关联数组：["a" => 1]。
  • count() 取长度，foreach 遍历。
  • 常用函数：array_push、array_keys、sort、implode。
arrays.php 
<?php
$fruits = ["apple", "banana", "cherry"];
$fruits[] = "date";
echo "数量：" . count($fruits) . "\n";

foreach ($fruits as $f) {
    echo "- $f\n";
}

$scores = ["math" => 95, "english" => 88];
foreach ($scores as $subject => $score) {
    echo "$subject: $score\n";
}

echo implode(", ", $fruits) . "\n";
?>
运行结果（示意）
数量：4
- apple
- banana
- cherry
- date
math: 95
english: 88
apple, banana, cherry, date
