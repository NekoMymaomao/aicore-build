表单与 GET/POST

PHP 最典型的用途之一：接收表单提交的数据并处理。

知识点

  • $_GET 接收 URL 查询参数，$_POST 接收表单体。
  • 输出用户输入前要用 htmlspecialchars() 转义，防止 XSS。
  • 用 isset() 判断参数是否存在。
form.php 
<?php
// 处理提交
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = $_POST["name"] ?? "";
    $safe = htmlspecialchars($name, ENT_QUOTES, "UTF-8");
    echo "收到：$safe\n";
} else {
    echo "请通过表单提交 name 字段\n";
}

// 模拟 GET 参数
$page = $_GET["page"] ?? "1";
echo "当前页：" . intval($page) . "\n";
?>
运行结果（示意）
请通过表单提交 name 字段
当前页：1
