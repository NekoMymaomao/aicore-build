第一个 PHP 程序

PHP 是嵌入在网页中的服务端脚本语言，由服务器执行后输出 HTML。

知识点

  • PHP 代码写在 <?php ... ?> 之间。
  • echo / print 输出内容。
  • 语句以分号结尾；运行：php hello.php。
hello.php 
<?php
// 第一个 PHP 程序
echo "Hello, World!\n";
echo "欢迎学习 PHP\n";

$name = "小明";
echo "你好，" . $name . "！\n";
?>
运行结果（示意）
Hello, World!
欢迎学习 PHP
你好，小明！
