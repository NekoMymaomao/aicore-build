运算符与流程控制

运算符用于计算，流程控制决定执行路径。

知识点

  • 拼接字符串用 .（点号），不是 +。
  • if / elseif / else、switch、for、foreach。
  • 松散比较 == 与严格比较 === 有区别。
control.php 
<?php
$score = 86;
if ($score >= 90) {
    echo "优秀\n";
} elseif ($score >= 60) {
    echo "及格\n";
} else {
    echo "不及格\n";
}

$sum = 0;
for ($i = 1; $i <= 5; $i++) {
    $sum += $i;
}
echo "1+2+3+4+5 = $sum\n";
?>
运行结果（示意）
及格
1+2+3+4+5 = 15
