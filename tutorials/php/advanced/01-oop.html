面向对象

PHP 支持完整的面向对象：类、继承、接口、抽象类。

知识点

  • class / new；__construct 是构造方法。
  • extends 继承，interface 定义契约。
  • 可见性 public / protected / private。
oop.php 
<?php
interface Speaker {
    public function speak(): string;
}

class Animal {
    public function __construct(protected string $name) {}
}

class Dog extends Animal implements Speaker {
    public function speak(): string { return "汪汪"; }
}

class Cat extends Animal implements Speaker {
    public function speak(): string { return "喵喵"; }
}

foreach ([new Dog("旺财"), new Cat("咪咪")] as $a) {
    echo $a->name . " 说 " . $a->speak() . "\n";
}
?>
运行结果（示意）
旺财 说 汪汪
咪咪 说 喵喵
