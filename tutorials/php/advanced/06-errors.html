错误处理与命名空间

异常处理与命名空间让大型项目更健壮、更易组织。

知识点

  • try / catch / finally 捕获异常，throw 抛出。
  • 自定义异常继承 Exception。
  • namespace 隔离命名，use 引入；配合 Composer 自动加载。
errors.php 
<?php
class ValidationException extends Exception {}

function checkAge(int $age): void {
    if ($age < 0) {
        throw new ValidationException("年龄不能为负数");
    }
}

try {
    checkAge(-1);
} catch (ValidationException $e) {
    echo "校验失败：" . $e->getMessage() . "\n";
} finally {
    echo "检查结束\n";
}

// 命名空间
namespace App\Utils;
function version() { return "1.0"; }
echo "版本：" . version() . "\n";
?>
运行结果（示意）
校验失败：年龄不能为负数
检查结束
版本：1.0
