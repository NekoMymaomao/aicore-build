字符串与正则

PHP 内置大量字符串函数，并支持 PCRE 正则。

知识点

  • 常用函数：strlen、str_replace、substr、strtoupper。
  • 正则：preg_match / preg_replace，模式需带分隔符如 /.../。
  • sprintf 做格式化输出。
strings.php 
<?php
$s = "hello java";
echo strlen($s) . "\n";
echo strtoupper($s) . "\n";
echo substr($s, 0, 5) . "\n";
echo str_replace("java", "php", $s) . "\n";

if (preg_match("/\d{4}-\d{2}-\d{2}/", "2026-10-16", $m)) {
    echo "匹配到日期：" . $m[0] . "\n";
}

echo sprintf("价格：%.2f 元\n", 12.5);
?>
运行结果（示意）
10
HELLO JAVA
hello
hello php
匹配到日期：2026-10-16
价格：12.50 元
