文件与目录

PHP 可以读写文件、遍历目录，常用于日志和配置处理。

知识点

  • file_put_contents 一步写入，file_get_contents 一步读取。
  • fopen / fgets / fclose 逐行处理大文件。
  • scandir / glob 列出目录内容。
files.php 
<?php
$file = "demo.txt";
file_put_contents($file, "第一行\n第二行\n");

$content = file_get_contents($file);
echo $content;

if (($fh = fopen($file, "r")) !== false) {
    while (($line = fgets($fh)) !== false) {
        echo "读取：" . trim($line) . "\n";
    }
    fclose($fh);
}

echo "文件存在：" . (file_exists($file) ? "是" : "否") . "\n";
?>
运行结果（示意）
第一行
第二行
读取：第一行
读取：第二行
文件存在：是
